# Ember

A self-hosted controller for the Kamado Joe iKamand. It runs on a Synology NAS and is used from an
iPhone as an installed web app over Tailscale.

- What it does: `docs/brief.md`
- How it talks to the grill: `docs/protocol.md`
- Build plan and status: `docs/milestones.md`
- Deploying to the NAS: `docs/deploy.md`
- Design: `design/`
- Protocol references (MIT): `reference/`. These are copies of
  [plmilord/Hass.io-custom-component-ikamand](https://github.com/plmilord/Hass.io-custom-component-ikamand)
  and [slinkymanbyday/ikamand](https://github.com/slinkymanbyday/ikamand).
